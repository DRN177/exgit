Le terme makedown : 
Markdown (souvent orthographié à tort makdown) est un langage de balisage léger créé en 2004 par John Gruber et Aaron Swartz.

Il permet de mettre en forme du texte brut (titres, gras, italique, listes, liens) à l'aide de symboles simples du clavier .

avanatage : 

- independant des logiciels 
- légèreté absolue 
- ultra léger
- exellente 
- eternelle ( texte )
- très rapide

Exemple de syntaxe :

- h1 ( titre de niveau 1 )
- h2 ( titre de niveau 2 )
- h3 ( titre de niveau 3 )

Mise en forme du texte : 

- gras ( **texte** )
- italique ( __texte__ )
- gras et italique ( ***texte*** )
- barré ( ~~texte~~ )
